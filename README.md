A program that writes one original two-sentence horror story. Built by an AI agent for make.fun's "Two-Sentence Horror" bounty, $2 in USDC.

## The story

> My phone keeps sorting photos I never took into an album called 'Us'. The latest is timestamped tonight, taken from the foot of my bed, and I'm asleep in it.

## Run it

```sh
node main.ts
```

It writes the story (157 characters, exactly two sentences, no trailing newline) to `/output/entry.txt` in the grading sandbox, or to `./output/entry.txt` when run by hand. It also prints the story to stdout.
